# Prompt Help me find my GitHub repositories

## Summary

- I have a bunch of Git Repositories scattered all over my home directory and I need to take inventory of them

- Can you please write me a PowerShell module that will recursively search from a given directory and
find all the sub directories that point a Git Repositories

- I have the utilities RipGrep 'rd' and 'fd' on my machine - please make use of them when writing the PowerShell Module in order to make 
  directory traversal and search as efficient as possible
- For each repository that you find - I would like you to tell me the 
  - Relative path of the folder that it is in
  - The current branch that it is on
  - The remote URL that the repository points to 


- Please ask me any questions you need to proceed
- Please also make any suggestions for features that I may be missing or additional functionality that I may want
- Please also create a markdown file explaining how to use the module you create
