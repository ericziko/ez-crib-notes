# Obsidian Claude AI Plugins - Complete Reference

A comprehensive guide to all available Obsidian plugins that integrate Claude AI directly into your notes and vault.

---

## Summary

Several Obsidian plugins enable direct Claude AI integration for conversation, coding assistance, and note enhancement. These plugins bring Claude's agentic capabilities into your note-taking workflow without requiring terminal access or context switching.

---

## Plugins

### 1. **Claudian** ⭐ (Most Comprehensive)

**Description:**  
An Obsidian plugin that embeds Claude Code as an AI collaborator directly in your vault. Provides a sidebar chat interface with full agentic capabilities including file read/write, bash command execution, vision support, MCP server integration, and multi-step workflows.

**Key Features:**
- Sidebar chat interface with multiple tabs for parallel conversations
- Full Claude Code agent capabilities (file operations, bash, vision)
- Conversation history and fork/resume functionality
- Compact mode options
- Support for multi-step AI workflows

**Repository:** https://github.com/YishenTu/claudian

**Obsidian Community Plugin:** Available in Obsidian plugin marketplace

---

### 2. **Claude Sidebar**

**Description:**  
A lightweight plugin that embeds Claude Code in your Obsidian sidebar. Designed for quick access without terminal navigation.

**Key Features:**
- One-click access to Claude Code from sidebar
- Multiple tabs for parallel conversations
- No terminal or folder navigation required
- Streaming responses

**Forum Post:** https://forum.obsidian.md/t/claude-code-from-the-sidebar/109634

---

### 3. **Claude Code Integration Plugin**

**Description:**  
Interactive Claude Code integration for Obsidian. Brings full AI coding assistant capabilities directly into your vault with context-aware understanding of note content and vault structure.

**Key Features:**
- Edit notes intelligently with Claude
- Generate text and create diagrams
- Automate repetitive tasks
- Streaming responses
- Full tool capabilities (bash, file operations)

**Repository:** https://github.com/deivid11/obsidian-claude-code-plugin

---

### 4. **Agent Client**

**Description:**  
Brings Claude Code, Codex, and Gemini CLI inside Obsidian. A unified interface for running multiple AI agents directly in your vault.

**Key Features:**
- Support for multiple AI agents (Claude, Codex, Gemini)
- Direct CLI integration within Obsidian
- Parallel agent execution

**Forum Post:** https://forum.obsidian.md/t/new-plugin-agent-client-bring-claude-code-codex-gemini-cli-inside-obsidian/108448

---

### 5. **Obsidian AI Agent** (m-rgba/obsidian-ai-agent)

**Description:**  
An integrated AI agent plugin for Obsidian currently powered by Claude Code. Maintains Claude's context-awareness of your Obsidian environment with a file-first approach.

**Key Features:**
- AI context-aware of vault structure
- File-first approach (read, edit, create files)
- Direct chat interface with Claude
- Vault integration

**Repository:** https://github.com/m-rgba/obsidian-ai-agent

---

### 6. **CAO - Claude AI for Obsidian**

**Description:**  
A basic Claude AI integration plugin allowing direct conversation with Claude within your notes.

**Key Features:**
- Simple conversation interface
- Claude AI powered responses
- Direct integration in notes

**Plugin Link:** https://www.obsidianstats.com/plugins/cao

---

### 7. **Claude-Obsidian Knowledge Companion**

**Description:**  
A knowledge companion system based on Claude and Obsidian, implementing Karpathy's LLM Wiki pattern. Creates a persistent, compounding wiki vault that grows and improves over time.

**Key Features:**
- Persistent wiki vault
- Karpathy's LLM Wiki pattern implementation
- Compounding knowledge structure
- `/wiki`, `/save`, `/autoresearch` commands

**Repository:** https://github.com/AgriciDaniel/claude-obsidian

---

### 8. **Native Obsidian Claude Code Plugin** (Roasbeef)

**Description:**  
A native Obsidian plugin that embeds Claude as an AI assistant directly within your vault, providing seamless integration with note-taking workflows.

**Key Features:**
- Native Obsidian integration
- Claude embedded in vault interface
- Direct AI assistant access

**Repository:** https://github.com/Roasbeef/obsidian-claude-code

---

## Comparison & Recommendations

### For Maximum Capability:
**Claudian** is the most mature and feature-rich option. It provides full Claude Code agent capabilities (file operations, bash commands, vision, MCP servers) in a sidebar interface.

### For Lightweight Integration:
**Claude Sidebar** or **CAO** offer simpler, more focused Claude conversation without the overhead of full agent capabilities.

### For Knowledge Workflows:
**Claude-Obsidian Knowledge Companion** is ideal if you want to build a growing, interconnected knowledge base with Claude assistance.

### For Code-Heavy Work:
**Claude Code Integration Plugin** or **Agent Client** provide robust coding assistance within your notes.

---

## Installation

Most plugins are available through the Obsidian Community Plugin marketplace:
1. Open Settings → Community Plugins
2. Search for the plugin name
3. Click Install and Enable

For GitHub-hosted plugins not yet in the marketplace, use **BRAT** (Bloodhound Repo Assistant Tool) plugin to install from GitHub URLs.
